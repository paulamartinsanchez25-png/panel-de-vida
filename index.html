🧩 Herramientas

Configurar conexión con Google
  1. En Google Cloud, crea un proyecto y activa Calendar API, Gmail API y Drive API.
  2. Crea un ID de cliente OAuth tipo "Aplicación web" y añade como origen autorizado la dirección donde abras esta página (https o localhost).
  3. Añade tu correo como usuario de prueba y pega el ID aquí. Solo se pide acceso de lectura.
